# Buyback Programs 1.0.0-rc.3

`1.0.0-rc.3` is a focused regression-fix release candidate for policy
validation introduced in `1.0.0-rc.2`.

## Fixed

- Allow corrective and non-worsening Program and rule edits when previously
  persisted policy paths are already outside the supported effective modifier
  bounds. Newly introduced or worsened violations remain blocked.
- Distinguish valid TYPE `REPLACE` rules at the exact `-100%` and `+100%`
  boundaries from TYPE `ADJUST` compositions that exceed those bounds.
- Present structured, deduplicated policy diagnostics once in the administration
  UI, with the affected policy path and percentage values.

Runtime policy evaluation remains fail-closed when an invalid effective
modifier reaches appraisal or Quote creation.

## Upgrade

This release changes no database schema and adds no configuration migration.
Upgrade through Composer, run the standard migration and SeAT plugin permission
seeder steps, clear application caches, and verify Program and rule editing plus
the appraisal-to-Request smoke path.

Read [installation.md](../installation.md) and [upgrading.md](../upgrading.md)
before updating a deployment.
