# Buyback Programs 1.0.0-rc.2

`1.0.0-rc.2` is a regression-fix release candidate for Buyback Programs on
SeAT 5.

## Fixed

- Resolve pasted appraisal item names using case-insensitive exact matching
  while preserving canonical EVE type identity and non-fuzzy behavior.
- Reject composed effective policy modifiers outside the supported `-100%`
  through `+100%` domain, including invalid combinations saved while a Program
  is disabled.

## Upgrade

Upgrade through Composer, run migrations and the SeAT plugin permission seeder,
clear application caches, and validate the appraisal-to-Request smoke path. This
release adds no new plugin migration, but running the standard migration step
keeps the installation procedure consistent and safe.

Read [installation.md](../installation.md) and [upgrading.md](../upgrading.md)
before updating a deployment.
