# Buyback Programs 1.0.0-rc.5

`1.0.0-rc.5` is the targeted requester-workflow clarification candidate. The
currently published `1.0.0-rc.4` release and tag remain unchanged. This document
prepares the next candidate; it does not publish, tag, or release it.

## Requester workflow

After appraisal, requesters now receive two sibling actions:

```text
Save Quote
Create Buyback Request
```

**Save Quote** creates or reuses the immutable Quote and opens its saved state.
No Buyback Request exists yet, and the interface warns the requester not to
create an EVE contract.

**Create Buyback Request** creates or reuses that same Quote, immediately
creates or reuses its one Buyback Request, and opens Request detail with the
contract next steps. The orchestration composes the existing production Quote
creation and Quote-submission services; it does not duplicate their rules.

If Request creation fails after Quote creation, the immutable Quote remains
saved under **Unsubmitted Quotes**. A later retry reuses the same Quote and
cannot create duplicate Quotes or Requests.

## References and contract guidance

- **My Buybacks** calls saved valid offers **Unsubmitted Quotes** and explains
  that they have not entered fulfillment.
- Ordinary requester and manager views no longer display Quote public IDs.
  Quote route parameters and the Quote-creation JSON response retain technical
  identity where transport/API addressing requires it.
- The Buyback Request public ID is the only operational EVE contract reference
  shown to requesters and managers.
- Request detail provides a copy-to-clipboard action, ordered contract steps,
  the quoted total and items, Program-specific contract instructions, and the
  existing optional contract-ID field.

## Theme compatibility

Quantity and monetary columns in appraisal, Quote, and Request item tables now
inherit the active SeAT theme's row text color. This keeps those values readable
with dark Iuligigi and Gigigraphite backgrounds without hard-coding a light or
dark palette.

Side-by-side cards on requester and manager detail pages now fill the complete
height of their Bootstrap row, keeping card boundaries and action footers aligned
when neighboring forms have different content heights.

## Compatibility and upgrade impact

This candidate changes no database schema, Quote/Request aggregate semantics,
permission identifiers, pricing behavior, or Request state machine. Existing
valid saved Quotes—including those whose Program is now disabled or
archived—remain eligible to create a Request until expiration. Existing
Requests and immutable historical evidence are unchanged.

The development Composer policy records the additional Laravel 10 debug-page
XSS advisory `PKSA-d5tc-s1qs-h781` as a focused ADR 0013 exception because SeAT
5 cannot move this plugin independently to a patched Laravel major. Advisory
blocking and audit failure remain enabled for every unreviewed advisory. The
exception requires production deployments to keep `APP_DEBUG=false` and debug
exception pages unavailable to untrusted users.

After upgrading, clear application caches and restart long-running workers by
the normal package procedure, then smoke-test both appraisal actions and the
Request-reference contract workflow. No new release is published as part of
this preparation.
