# Contributing

This project is in release-candidate stabilization. Public source and releases
use a clean release-only GitHub history, but active development, issue authority,
reviews, and CI remain in the project's private GitLab environment during this
phase.

The public contribution and issue-reporting workflow is not yet finalized and
will begin after stable `1.0.0` is validated and the recorded authority cutover
is complete. At that point GitHub issues, pull requests, `main`, CI, and releases
become authoritative and GitLab becomes archival or downstream-only. Please do
not assume the transition has occurred until the repository announces it.

Security reports should follow [SECURITY.md](SECURITY.md).
